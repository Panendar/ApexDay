# User can export all data and delete my account

## Story
As a user, I can export all history as CSV or JSON, get printable weekly and monthly PDF reports, and delete my account.

## Purpose
Users own their data.

Serves intent goal: G6

## Behaviour and acceptance criteria
- Full export is always available in CSV and JSON
- Weekly and monthly reports can be printed as PDF
- Account deletion removes all server data within 30 days
- Data is never deleted for inactivity

## Order
Order: 61 of 70
Group: 5. Accounts, sync and data
Depends on: User can see progress by day, week, month, year and lifetime
