# User can lock the day to commit to the plan

## Story
As a user, I can press Start my day so later edits ask for one confirmation.

## Purpose
A committed plan feels real.

Serves intent goal: G6

## Behaviour and acceptance criteria
- Lock the day via Start my day
- After locking, each edit asks for one confirmation
- The day can be unlocked by the user

## Order
Order: 17 of 70
Group: 1. Foundation
Depends on: User can add a timed task to the day timeline
