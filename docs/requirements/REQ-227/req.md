# User can see tomorrow's Top 3 suggested from the End of Day card

## Story
As a user, I can get tomorrow's Top 3 suggestion at the end of the day and open Plan Tomorrow.

## Purpose
This links the evening ritual to tomorrow's plan.

Serves intent goal: G1

## Behaviour and acceptance criteria
- The End of Day card suggests tomorrow's Top 3
- One click opens Plan Tomorrow
- The suggestion is not applied without confirmation

## Order
Order: 48 of 70
Group: 4. Progress and motivation
Depends on: User can close the day with an End of Day card; User can pin a Top 3 and a day intention
