# User can see estimate accuracy and best-time insights, and get duration suggestions

## Story
As a user, I can see planned versus actual time by category, my most productive hours, and a suggested duration after 5 similar tasks.

## Purpose
Honest estimates make plans realistic.

Serves intent goal: G1

## Behaviour and acceptance criteria
- Planned vs actual by category with suggestions such as "Study blocks run 20% longer than planned"
- Best-time insight shows the most productive hours
- After 5 completed similar tasks, planning suggests a duration from the median actual time

## Order
Order: 43 of 70
Group: 4. Progress and motivation
Depends on: User can see progress by day, week, month, year and lifetime; User can set a task's time window and run a timer inside it
