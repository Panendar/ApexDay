# User can schedule the rest of a partly done task

## Story
As a user, I can create a follow-up for the remaining minutes and see what was achieved.

## Purpose
A partial effort should lead to a plan for the remainder.

Serves intent goal: G4

## Behaviour and acceptance criteria
- Needs attention says what was achieved and offers Continue now, Schedule the rest, Mark done anyway, Move to tomorrow
- Schedule the rest creates a follow-up for the remaining minutes
- Nothing is completed or moved without the user's action

## Order
Order: 28 of 70
Group: 2. Start support
Depends on: User can see partial progress counted fairly
