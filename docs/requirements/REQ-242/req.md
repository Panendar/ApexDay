# User can get through first-run onboarding and an optional tour

## Story
As a user, I can pick a goal, pick a theme, add three tasks and optionally take a 30-second tour.

## Purpose
The first minutes decide retention.

Serves intent goal: G1

## Behaviour and acceptance criteria
- Three steps: pick a goal, pick a theme, add the first three tasks; a sample routine is seeded so no screen is empty
- Notification permission is asked only after the first completed task
- A skippable 30-second tour covers quick-add, Space to complete and Shift

Group: 6. Launch
Depends on: User can see Today with a Now card, Up next and a day ring
