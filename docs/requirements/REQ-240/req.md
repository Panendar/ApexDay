# User can import tasks from CSV or a plain-text list

## Story
As a user, I can import tasks from a CSV or paste a list with one task per line using the quick-add grammar.

## Purpose
Moving in should be quick.

Serves intent goal: G1

## Behaviour and acceptance criteria
- CSV import works
- Plain-text lists use one task per line with the quick-add grammar
- A preview shows what will be added
