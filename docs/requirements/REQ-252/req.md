# User can spread tasks evenly or stack them

## Story
As a user, I can select tasks and distribute them evenly across a window or remove gaps between them.

## Purpose
Bulk time tools tidy a day quickly.

Serves intent goal: G1

## Behaviour and acceptance criteria
- Distribute evenly spreads selected tasks across a chosen window
- Stack tasks removes gaps between selected tasks
- Both preview and can be undone

## Order
Order: 36 of 70
Group: 3. Shift engine
Depends on: User can move and resize tasks by dragging
