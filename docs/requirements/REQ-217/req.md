# College student can track class attendance

## Story
As a college student, I can mark classes attended, absent or cancelled and see attendance percentage and classes I can still miss.

## Purpose
Many colleges require 75% attendance.

Serves intent goal: G2

## Behaviour and acceptance criteria
- Each class can be marked attended, absent or cancelled
- Cancelled classes free time, offer a suggested study task, and are not counted against the user
- Attendance percentage per subject warns below a user-set limit (many colleges require 75%) and shows classes you can still miss
