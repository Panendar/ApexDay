# User can track subtask progress and use quick actions on cards

## Story
As a user, I can see partial progress from subtasks on a card and use +10 min, +30 min, snooze 15, move to tomorrow, make fixed and add subtask.

## Purpose
Small adjustments should not need a full edit.

Serves intent goal: G1

## Behaviour and acceptance criteria
- A card with subtasks shows partial progress on the card and ring
- Completing the last subtask offers to complete the task
- Hover or long-press reveals +10 min, +30 min, snooze 15 min, move to tomorrow, make fixed, add subtask
- Moving a task keeps the original with status moved

## Order
Order: 16 of 70
Group: 1. Foundation
Depends on: User can see Today with a Now card, Up next and a day ring
