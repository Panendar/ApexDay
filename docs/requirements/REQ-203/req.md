# User can enter Focus Mode for a task

## Story
As a user, I can press F or Start to open a full-screen view with a timer ring, subtask checklist and Done button.

## Purpose
Distraction-free focus makes starting easier.

Serves intent goal: G4

## Behaviour and acceptance criteria
- Pressing F or Start opens Focus Mode in under 3 seconds
- It shows the title, a large timer ring, subtasks as a checklist and one Done button
- A park-a-thought box sends ideas to the Inbox without leaving
- Leaving Focus Mode never loses tracked time; interruptions are counted, not judged
- Ambient sound is optional and off by default

## Order
Order: 22 of 70
Group: 2. Start support
Depends on: User can set a task's time window and run a timer inside it; User can capture a thought to the Inbox and promote it to a task
