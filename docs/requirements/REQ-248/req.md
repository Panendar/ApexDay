# User can see light seasonal events

## Story
As a user, I can see time-limited visuals such as exam season or festival days that change look only.

## Purpose
Seasonal events add freshness.

Serves intent goal: G3

## Behaviour and acceptance criteria
- Events change look only, never rules
- They are time limited
- They can be turned off
