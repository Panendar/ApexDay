# User can opt in to daily quests

## Story
As a user, I can turn on one light rotating challenge per day that only gives XP.

## Purpose
Quests add a light daily reason to return.

Serves intent goal: G3

## Behaviour and acceptance criteria
- Quests are opt-in, one per day
- They reward XP only, never gate features and are never shown as failed
- Minimal mode hides them

Order: 69 of 70
Group: 7. Growth
