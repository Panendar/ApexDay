# User can break a task into small subtasks

## Story
As a user, I can turn a task into 3-5 subtasks typed or picked from templates and see the first one highlighted.

## Purpose
Smaller steps make it easier to begin.

Serves intent goal: G4

## Behaviour and acceptance criteria
- Break it down turns a task into 3-5 subtasks typed or from simple templates
- Each subtask can be given a time slice
- The first subtask is highlighted as start here
- Nothing is added without the user's approval

## Order
Order: 24 of 70
Group: 2. Start support
Depends on: User can track subtask progress and use quick actions on cards
