# User can move and resize tasks by dragging

## Story
As a user, I can drag a task to change its time, drag its edge to change duration, drag between days in the week view and edit several tasks at once.

## Purpose
Fast rearranging keeps planning under 2 minutes.

Serves intent goal: G1

## Behaviour and acceptance criteria
- Dragging a task changes its time; dragging its edge changes its duration; both snap to a grid of 5, 10, 15 or 30 minutes
- Tasks can be dragged between days in the week view
- Multi-select supports bulk move, delete or recolour
- Tasks can be moved with the arrow keys as a drag alternative

## Order
Order: 4 of 70
Group: 1. Foundation
Depends on: User can add a timed task to the day timeline
