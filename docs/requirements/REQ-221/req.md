# User can set goals linked to tasks and habits

## Story
As a user, I can create long-term goals and see progress with a projected finish date.

## Purpose
Goals connect daily tasks to what matters.

Serves intent goal: G3

## Behaviour and acceptance criteria
- A goal has title, category, target type (hours, tasks, habit_days, date), value and due date
- Tasks and habits can link to a goal; progress bars show a pace marker and projected finish
- Deleting a goal keeps linked tasks unlinked and archives goal history
