# User can do a weekly planning ritual

## Story
As a user, I can follow a guided three-step flow: review last week, set the week's goal and drop big tasks onto days.

## Purpose
A weekly ritual sets the direction.

Serves intent goal: G1

## Behaviour and acceptance criteria
- The flow is offered on the user's planning day (default Sunday evening)
- It has three steps: review last week, set the week's goal, drop big tasks onto days
- Finishing earns a small reward and sets the week's headline
