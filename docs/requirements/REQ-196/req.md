# User can see Today with a Now card, Up next and a day ring

## Story
As a user, I can open Today and see the current task with a live countdown, the next task, the whole day as cards and a ring of progress.

## Purpose
Today is where the day is run.

Serves intent goal: G1

## Behaviour and acceptance criteria
- Today shows a Now card with a live countdown ring, an Up next card, the day as cards, and a Top 3 strip
- The browser tab title and favicon show the current task and a progress ring
- Everything updates live as time passes
- Reminders fire at task start and a configurable lead time

## Order
Order: 13 of 70
Group: 1. Foundation
Depends on: User can add a timed task to the day timeline
