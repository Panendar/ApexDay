# User can import and export calendars and get holiday prompts

## Story
As a user, I can import and export ICS files and feeds and choose a holiday calendar by country and state with a Shift your plan? prompt.

## Purpose
Holidays are the main cause of shifts.

Serves intent goal: G2

## Behaviour and acceptance criteria
- ICS import and export by feed and file
- Holiday calendars by country and state
- A newly added holiday prompts "Shift your plan?"

## Order
Order: 67 of 70
Group: 7. Growth
Depends on: User can preview, apply and undo a shift as one batch
