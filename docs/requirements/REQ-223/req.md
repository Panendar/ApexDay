# User can see Start rate and Rescued-tasks insights

## Story
As a user, I can see how many planned tasks got focus time and how many nudged tasks reached 20%.

## Purpose
Encouraging insights reward starting.

Serves intent goal: G3

## Behaviour and acceptance criteria
- Start rate is the share of planned tasks with at least 1 minute of focus
- Rescued tasks are nudged tasks that reach at least 20% of planned time
- Wording is encouraging, for example "Your 5 + 2 sprints turned 12 skipped tasks into progress"

## Order
Order: 44 of 70
Group: 4. Progress and motivation
Depends on: User can see progress by day, week, month, year and lifetime; User can get a calm Start nudge when a task has not started
