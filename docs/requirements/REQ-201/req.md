# User can use a base theme with consistent design tokens

## Story
As a user, I can use the app in a light and dark theme with the app's spacing, type scale and motion tokens.

## Purpose
Design is a requirement and every later screen builds on these tokens.

Serves intent goal: G5

## Behaviour and acceptance criteria
- Light and dark themes exist with text contrast of at least 4.5:1
- Layout is responsive: three panes at 1200 px and up, two panes 768-1199 px, one column with bottom tab bar 360-767 px
- Motion tokens are defined: instant 100, quick 200, standard 350, emphasised 600, celebration 1500+ ms

Group: 1. Foundation
Depends on: none
