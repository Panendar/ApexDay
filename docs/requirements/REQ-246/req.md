# College student can share a read-only timetable link

## Story
As a college student, I can share a timetable by link and let classmates import their own copy.

## Purpose
Classmates share the same timetable.

Serves intent goal: G2

## Behaviour and acceptance criteria
- A read-only link can be shared
- Importers keep their own copy
- If the shared timetable changes, importers get an optional "update available" prompt

## Order
Order: 68 of 70
Group: 7. Growth
Depends on: College student can define a day-order timetable and re-align later dates; User can use guest mode and then sign in without losing data
