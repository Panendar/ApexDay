# User can use supportive tips and a Stuck? picker

## Story
As a user, I can see short tips by context and pick why they are stuck to get a matching action.

## Purpose
Tips lower the barrier to starting.

Serves intent goal: G4

## Behaviour and acceptance criteria
- The library has at least 50 tips by context (big, boring, tired, slump, missed start, general)
- Tips show in the nudge, in Focus Mode before the timer, and in a Stuck? drawer
- Tone follows the setting (calm, energetic, tough love); users can hide a tip or turn tips off
- Stuck? offers reasons (too big, boring, don't know where to start, tired, distracted) with matching actions

## Order
Order: 26 of 70
Group: 2. Start support
Depends on: User can start a task with a Tiny Start; User can break a task into small subtasks
