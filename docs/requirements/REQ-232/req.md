# User can turn on minimal mode

## Story
As a user, I can hide XP and quests and keep only the day ring and streak.

## Purpose
Gamification must stay optional and quiet.

Serves intent goal: G3

## Behaviour and acceptance criteria
- A minimal mode setting hides XP and quests
- Only the day ring and streak remain
- The setting can be turned off again
