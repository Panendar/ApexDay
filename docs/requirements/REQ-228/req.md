# User can see the Momentum bar

## Story
As a user, I can see a thin bar for completions in a row today.

## Purpose
Momentum motivates without punishment.

Serves intent goal: G3

## Behaviour and acceptance criteria
- A thin bar under the header shows "3 in a row" for the current day
- It resets gently at midnight
- It has no penalty side

## Order
Order: 49 of 70
Group: 4. Progress and motivation
Depends on: User can complete a task in one click with Undo and a short animation
