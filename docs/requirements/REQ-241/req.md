# College student can import a timetable from CSV or a pasted table

## Story
As a college student, I can import class slots from a CSV or a pasted table.

## Purpose
Colleges publish timetables as tables.

Serves intent goal: G2

## Behaviour and acceptance criteria
- CSV or pasted table imports into a timetable
- A preview shows slots before saving
