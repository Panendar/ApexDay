# User can operate the whole app by keyboard and with a screen reader

## Story
As a user, I can use shortcuts, move tasks with arrow keys, and rely on labels and reduced motion.

## Purpose
Accessibility is a requirement.

Serves intent goal: G5

## Behaviour and acceptance criteria
- Shortcuts work: N, I, Space, F, S, T, / or Ctrl/Cmd+K, arrows, ?
- Full keyboard operation with visible focus and drag alternatives
- Screen-reader labels for cards, rings and charts; text zoom to 200%; WCAG 2.2 AA
- State is never colour-only

## Order
Order: 55 of 70
Group: 4. Progress and motivation
Depends on: User can see Today with a Now card, Up next and a day ring
