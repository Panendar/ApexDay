# User can save a task as a template and reuse it

## Story
As a user, I can save a task with its subtasks and reminder as a template available in quick-add.

## Purpose
Repeated tasks should take seconds to add.

Serves intent goal: G1

## Behaviour and acceptance criteria
- Any task can be saved as a template with its subtasks and reminder
- Templates appear as options in quick-add
- Using a template creates a new task and does not link it to the template

## Order
Order: 11 of 70
Group: 1. Foundation
Depends on: User can add tasks by typing natural text
