# User can get weekly and monthly review cards

## Story
As a user, I can see wins, a gentle lowlight and a goal for next period, shareable as an image without task titles by default.

## Purpose
Reviews close the loop.

Serves intent goal: G3

## Behaviour and acceptance criteria
- A review card shows wins, a gentle lowlight and a goal for the next period
- It can be shared as an image that excludes task titles by default
- Reflections can be saved

## Order
Order: 45 of 70
Group: 4. Progress and motivation
Depends on: User can see progress by day, week, month, year and lifetime
